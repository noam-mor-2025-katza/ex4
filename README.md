תיעוד הפרויקט – ניהול חנות ומלאי

תשובות לשאלות ההבנה (חלק ד')

מדוע צריך גם Product[] וגם int[]? מה שומר כל מערך?
המערך products שומר את המוצרים עצמם עם הפרטים שלהם והמערך soldCount שומר כמה יחידות נמכרו מכל מוצר לפי אותו מקום במערך

מדוע צריך את productCount ולא מספיק להסתמך על אורך המערך?
אורך המערך זה רק המקסימום שאפשר לשים בחנות ולא כמה מוצרים באמת הוספנו. productCount אומר לנו איפה המקום הפנוי הבא וככה גם לא נגיע לתאים ריקים (null) בלולאות

מה ההבדל בין nextId לבין id מבחינת השימוש ב-static?
id הוא רגיל אז לכל מוצר יש מספר משלו אבל nextId הוא static אז הוא משותף לכולם וככה כל מוצר חדש מקבל את המספר הבא בתור

מדוע לא נכון לאפשר שינוי חופשי של השדה stock בלי בדיקת תקינות?
כי אז יהיה אפשר לשים מלאי שלילי וזה לא הגיוני בחנות. כשבודקים לפני שמשנים המלאי תמיד נשאר 0 ומעלה ואפשר למכור רק אם יש מספיק

מה הבעיה האפשרית בהחזרת המערך הפנימי products מתוך getter?
אם מחזירים את המערך עצמו מי שמשתמש במחלקה מבחוץ יכול לשנות או למחוק מוצרים ישר מהמערך בלי לעבור דרך הפעולות של החנות ואז הספירה של המוצרים והמכירות תיהרס

מה ההבדל בין break לבין continue בפרויקט שלכם?
break עוצר את הלולאה לגמרי כשמוצאים את המוצר בחיפוש כדי לא להמשיך סתם ו-continue רק מדלג על מוצר שאזל מהמלאי וממשיך לבדוק את שאר המוצרים
